# MSA design assets

This directory preserves the source material used to reproduce the locked
breaking-news templates.

## Source master

- `source/MSA-Temps.ai` — editable Adobe Illustrator master and the source of
  the measured artboard geometry.

## Approved reference exports

- `references/S1.jpg` — silver story (9:16)
- `references/S2.jpg` — silver post (4:5)
- `references/G1.jpg` — gold story (9:16)
- `references/G2.jpg` — gold post (4:5)

## Required fonts

The licensed font binaries are intentionally excluded from Git. Place locally
licensed copies in `assets/fonts/` using the filenames documented in
`fonts/README.md` before rendering or releasing the templates.
